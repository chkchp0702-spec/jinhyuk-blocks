## 기록
### 11/3 19시 v23 — 💤 쉬는 친구 꿈결 연출
- 무엇을: 접속 안 하고 쉬는 친구가 사냥터에 보일 때 몸이 살짝 비치는 푸른 꿈빛(반투명·그림자 없음·검은 외곽선 숨김)으로 바뀌고, 발밑에 천천히 숨 쉬듯 커졌다 작아지는 꿈빛 고리(작은 별 무늬)가 돌고, 머리 위로 "Z" 세 개가 번갈아 둥실 떠오르며 커지다 사라짐. 그래픽 높음이면 몸 둘레에 별빛 가루가 천천히 솟음. 접속 중인 친구·나와 한눈에 구별됨.
- 어디를: 새 파일 03g-dream.js(DREAM.dreamify·make·tick·drop, 캔버스 무늬 3장 한 번만), 04c-mmo.js makeGhost·dropGhost·tickGhosts(55m 안에서만 보임). 재질은 그 친구 것만 복사. PointLight 없음.
- 확인: 844×390 에덴·아스가르드·인도에서 가짜 쉬는 친구 3명 스크린샷(처음엔 눈밭에서 하얗게 묻혀 안 보여 → 색을 더 푸르게·덜 투명하게), 오류 0.
### 11/3 19시 v21 — 기술 이펙트 다듬기
- 무엇을: 기술을 쓰면 발밑에 세계 색 마법진(육망성·룬 눈금)이 빙글 돌며 펼쳐짐. 범위 기술은 부드러운 빛 고리 2겹 + 하얀 안쪽 고리 + 흙먼지가 사방으로 퍼짐. 일직선 기술(미카엘의 창·천둥의 망치·포세이돈의 해일)은 앞으로 쭉 뻗는 빛줄기(하얀 심 + 진한 색 테두리, 가로·세로 두 장이라 어느 각도에서도 보임) + 잔상 + 땅에 그을린 자국 + 끝에서 충격파. 번개는 떨어진 자리에 충격파. 하누만 도약은 빛 줄무늬 잔상. 예전 하얀 공 폭발(fxFlash)은 부드럽게 퍼지는 빛으로.
- 어디를: 새 파일 03f-skillfx.js(SFX.runeAt·shock·dust·beamLine·speed·glow, 캔버스 무늬 5장 한 번만 만듦), 04-game.js useSkill, 03-core.js fxFlash. 눈·모래처럼 밝은 바탕에서 안 보이던 것 → 테두리는 색을 진하게 만든 보통 섞기로. 잔상·먼지는 그래픽 높음일 때 더 많이. PointLight 없음.
- 확인: 844×390 4세계 기술 전·후 비교(이펙트 시간을 멈춰 순간 포착), 오류 0.
### 11/3 14시 v20 — 세계별 하늘 분위기
- 무엇을: 아스가르드 = 북쪽 하늘에 초록·파랑·보라 오로라 커튼이 일렁임(밤엔 진하게, 낮엔 희미하게, 눈보라 땐 약하게). 에덴 = 낮에 황금 빛줄기가 비스듬히 내려옴. 인도 = 분홍 꽃잎이 빙글빙글 돌며 떨어짐. 올림푸스 = 먹구름 띠 + 3.5~8초마다 가지 친 번개가 앞쪽 땅에 내리꽂히고 구름이 번쩍·멀리 천둥 소리(폭풍 땐 2.5배 자주).
- 어디를: 새 파일 03e-atmo.js(ATMO.tick·strike), 06-ui.js 메인 루프에서 호출(미궁 안·중앙 광장에선 꺼짐). 보이는 세계 것만 그림, 세계당 그리기 1~3번, PointLight 없음, 꽃잎은 인스턴스 한 번.
- 확인: 카메라가 내려다보는 각도라 처음 하늘 높이 둔 것은 안 보였음 → 앞쪽 낮은 곳으로 옮김. 844×390 켜기/끄기 비교 스크린샷 4세계 · 번개 3장, 오류 0.
### 11/3 10시 v18 — 레벨업·승급 연출
- 무엇을: 레벨업하면 발밑에서 금빛 빛기둥이 하늘로 솟고, 고리 3개가 몸을 감싸며 떠오르고, 빛가루가 나선으로 솟음 + 화면 가장자리 금빛 번쩍 + 가운데 큰 글씨 "LEVEL UP / Lv N / 체력 +22 · 공격 +3"(햇살 무늬 회전). 승급은 세계 색 빛기둥 3겹·고리 5개·큰 계급 이름·진동. 배너가 떠 있는 동안 다른 알림은 아래로 내려 겹치지 않게.
- 어디를: 새 파일 03d-celebrate.js(fxPillar·fxRiseRing·fxRiseDust·lvBanner·tickLvBanner), 03-core.js gainXp·tickFX(f.tick), 04-game.js finishTrial, 06-ui.js 메인 루프, 01-head.html #lvup·#lvglow CSS. 배너는 CSS 애니메이션 대신 게임 시간으로 움직임. 낮음 그래픽은 빛기둥 1개·빛가루 적게.
- 확인: 844×390 레벨업·승급 스크린샷(처음엔 빛기둥이 너무 하얘서 굵기·밝기 줄임, 알림 글씨 겹침 고침), 효과 다 끝나면 FX 0개로 정리됨, 오류 0.
### 11/3 v16 — (사용자 요청) 가로 화면, 선명한 글씨, 높은 점프·피하기
- 무엇을: 가로 화면 배치(HUD·미니맵·버튼·전쟁 막대·창·첫 화면을 가로에 맞춤), 앱 설치(manifest)도 가로, 안드로이드는 가로 고정 시도, 세로로 들면 "가로로 돌려 주세요" 안내(그냥 세로 버튼). 이름표를 정수 픽셀 위치로 + 흐린 그림자 대신 또렷한 테두리, 알림 글씨도 테두리. 점프 높이 약 1.5m → 3m, 공중에서 한 번 더(2단 점프·한 바퀴 돌기), 공중 0.8m 위에서는 괴물·병사·화살·발구르기·PvP 공격을 "피함!".
- 어디를: 01-head.html(가로 미디어 쿼리·#rotate·글씨), 03-core.js(placeLabel·lockLand), 06-ui.js(jump·begin), 04-game.js(hurtPlayer), build.py(orientation).
- 확인: 844×390 가로 스크린샷(게임·첫 화면·전쟁 창), 390×844 세로 안내, 점프 회피(공중 데미지 0 · 땅 50), 오류 0.
### 11/3 v15 — (사용자 요청) 확대·축소 폭, 구글 지도 느낌 지도, 전쟁 다양화, 날아가는 무기
- 무엇을: 확대 0.6~4.5배(예전 0.55~1.8, 멀리 볼 때 안개·그림자 범위도 넓힘, 가까이 볼 때 낮은 각도). 지도 = 진짜 높이 음영·바다·숲·물·광장·건물 지붕·노란 큰길 바탕 + 점선 영토·빨간 핀·파란 내 위치·파란 길 안내 경로·나침반. 전쟁 = 공격대가 정면·왼쪽·오른쪽 세 갈래에서 분대로, 수비대는 제단 둘레 진, 궁수(화살 포물선)·창병(창 던지기)·전사·대장. 내 무기: 활은 화살, 지팡이는 마법탄, 창은 긴 찌르기 + 「던지기」 버튼(무기마다 창·손도끼·돌아오는 망치·단검 부채·화살비·큰 불덩이).
- 어디를: 06-ui.js(ZMIN/ZMAX·fitShadow·카메라), 04f-map.js(새 지도), 03-core.js(TREEPOS), 04b-war.js(병사 전부 새로), 04e-combat.js(투사체·던지기), 04-game.js(attack), 05-net.js(친구가 쏜 것 보이기), 01-head.html(던지기 버튼), 03c-models.js(꾸미기 무기에 창 2종).
- 확인: 헤드리스로 지도 2종·최대/최소 확대·전쟁(궁수·창병·세 갈래)·활/창 던지기 스크린샷, 오류 0.
