## 기록
### 11/2 v13 — 타격감: 데미지 숫자 + 히트 플래시
- 무엇을: 데미지 숫자가 몬스터 위에서 "톡" 커졌다 떠오르게(두꺼운 외곽선, 좌우로 살짝 흩어짐), 치명타는 금색·크게·흔들림+"치명타!", 금화는 노란색. 몬스터가 맞으면 0.15초 하얗게 번쩍, 내가 맞으면 빨갛게 번쩍.
- 어디를: 01-head.html(.lbl.dmg em, dmgPop/dmgCrit/dmgGain), 03-core.js floatDmg, 03b-visual.js hitTint(맞은 캐릭터만 재질 복사), 04-game.js 몬스터 루프, 06-ui.js 메인 루프.
- 확인: 고친 버그 — 예전엔 CSS 애니메이션이 위치를 덮어써서 숫자가 화면 왼쪽 위로 날아가 거의 안 보였음. 스크린샷으로 숫자가 몬스터 위에 뜨고, 맞은 몬스터만 하얘지는 것 확인(같은 종류 다른 몬스터는 그대로). 오류 0.
